1.1 Feature Vector (Exact Math)

1.2 TensorFlow.js Model (Observer-Only)
import * as tf from '@tensorflow/tfjs';

export function buildNDE() {
  const input = tf.input({ shape: [120, 11] });

  const x1 = tf.layers.conv1d({
    filters: 32,
    kernelSize: 5,
    activation: 'relu'
  }).apply(input);

  const x2 = tf.layers.conv1d({
    filters: 64,
    kernelSize: 3,
    activation: 'relu'
  }).apply(x1);

  const pooled = tf.layers.globalAveragePooling1d().apply(x2);

  const shared = tf.layers.dense({
    units: 64,
    activation: 'relu'
  }).apply(pooled);

  const anomalyType = tf.layers.dense({
    units: 8,
    activation: 'softmax',
    name: 'anomalyType'
  }).apply(shared);

  const severity = tf.layers.dense({
    units: 1,
    activation: 'sigmoid',
    name: 'severity'
  }).apply(shared);

  const confidence = tf.layers.dense({
    units: 1,
    activation: 'sigmoid',
    name: 'confidence'
  }).apply(shared);

  return tf.model({
    inputs: input,
    outputs: [anomalyType, severity, confidence]
  });
}

1.3 Explainability (Signal Attribution)

Lightweight gradient attribution:

export async function explain(model, input) {
  const grads = tf.tidy(() => {
    const tape = tf.grad(x =>
      model.predict(x)[1].mean()
    );
    return tape(input);
  });

  return grads.abs().mean(0).arraySync();
}

Which telemetry dimensions caused this alert

export function compilePatch(ast: PatchAST): CompiledPatch {
  verifyPatch(ast);

  const { target, change, bounds } = ast;

  function apply(config: any) {
    const current = getPath(config, target);

    let next: number;
    if (change.mode === "BY") {
      next = current + change.value;
    } else {
      next = change.value;
    }

    if (next < bounds.min || next > bounds.max) {
      throw new Error("Patch would violate bounds");
    }

    return setPath(config, target, next);
  }

  function rollback(config: any) {
    if (ast.rollback.restore === "previous") {
      return restorePrevious(config, target);
    }
    return restoreOriginal(config, target);
  }

  return {
    patchId: ast.patchId,
    version: ast.version,
    patchClass: ast.patchClass,
    targetPath: target,
    apply,
    rollback,
    bounds,
    ttlMs: ast.safety.ttlMs,
    metadata: {
      anomalyClass: ast.justification.anomaly,
      confidence: ast.justification.confidenceGte,
      evidence: ast.justification.evidence,
    },
  };
}

function setPath(obj: any, path: string, value: number): any {
  const clone = structuredClone(obj);
  const keys = path.split(".");
  let ref = clone;

  for (let i = 0; i < keys.length - 1; i++) {

  return clone;
}

PART I — FORMAL SPECIFICATION

The goal of formal methods here is not elegance.
It is to make illegal states unreachable.

A. What We Must Prove (Invariants)

Your APS must satisfy exactly these invariants:

Safety invariants (nothing bad happens)

No patch executes without approval

No patch exceeds its trust authority

No patch persists beyond its TTL

No unsigned patch executes

Rollback is always possible

Liveness invariants (something good happens)

Every applied patch eventually expires or is promoted

Every failed canary eventually rolls back

Trust decays if unused

These map cleanly to TLA+.

B. TLA+ Model (Core)
1️⃣ State Variables
VARIABLES
  patches,        \* All known patches
  applied,        \* Patches currently active
  approvals,      \* Human approvals
  trustLevel,     \* APS trust level
  time            \* Logical clock

2️⃣ Patch Record
Patch ==
  [ id        : STRING,
    class     : {"threshold", "routing", "suppression", "calibration"},
    ttl       : Nat,
    approved  : BOOLEAN,
    signed    : BOOLEAN,
    appliedAt : Nat
  ]

3️⃣ Initial State
Init ==
  patches = {} /\
  applied = {} /\
  approvals = {} /\
  trustLevel = 1 /\
  time = 0

4️⃣ Actions
ProposePatch
ProposePatch(p) ==
  p.approved = FALSE /\
  p.signed = FALSE /\
  patches' = patches ∪ {p}

ApprovePatch
ApprovePatch(p) ==
  p ∈ patches /\
  trustLevel >= RequiredTrust(p.class) /\
  approvals' = approvals ∪ {p.id} /\
  patches' = (patches \ {p}) ∪ { [p EXCEPT !.approved = TRUE] }

SignPatch
SignPatch(p) ==
  p.approved = TRUE /\
  patches' = (patches \ {p}) ∪ { [p EXCEPT !.signed = TRUE] }

ApplyPatch
ApplyPatch(p) ==
  p.approved = TRUE /\
  p.signed = TRUE /\
  applied' = applied ∪ { [p EXCEPT !.appliedAt = time] }

Tick (Time Progression)
Tick ==
  time' = time + 1

ExpirePatch
ExpirePatch(p) ==
  p ∈ applied /\
  time - p.appliedAt >= p.ttl /\
  applied' = applied \ {p}

5️⃣ Next-State Relation
Next ==
  ∃ p : ProposePatch(p)
  \/ ∃ p : ApprovePatch(p)
  \/ ∃ p : SignPatch(p)
  \/ ∃ p : ApplyPatch(p)
  \/ ∃ p : ExpirePatch(p)
  \/ Tick

C. Safety Invariants (THE IMPORTANT PART)
1️⃣ No unsigned patch executes
UnsignedNeverApplied ==
  ∀ p ∈ applied : p.signed = TRUE

2️⃣ TTL always enforced
NoExpiredPatch ==
  ∀ p ∈ applied :
    time - p.appliedAt < p.ttl

3️⃣ Trust authority never exceeded
TrustInvariant ==
  ∀ p ∈ applied :
    trustLevel >= RequiredTrust(p.class)

4️⃣ Approval required
ApprovalInvariant ==
  ∀ p ∈ applied :
    p.approved = TRUE

5️⃣ Combined Spec
Spec ==
  Init /\ [][Next]_<<patches, applied, approvals, trustLevel, time>>

D. Alloy Spec (Structural Guarantees)
