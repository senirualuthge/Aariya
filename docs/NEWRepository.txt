Repository 1: aariya-protocol

Purpose: Aariya's universal language.

Think of it as:

ROS 2 → Message Definitions
Kubernetes → API Objects
OpenAPI → API Contracts
Protocol Buffers → Schemas

No business logic.
No AI.
No planner.

Only data contracts.
