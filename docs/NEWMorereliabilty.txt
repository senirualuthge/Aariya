  Section 377: # memory/memory_manager.py (from NEWMorereliabilty.txt)

class MemoryManager:

    def __init__(self):

        self.working = {}
        self.short_term = []
        self.long_term = []
        self.knowledge = {}

    def store(self, memory):

        self.short_term.append(memory)

    def recall(self, query):

        results = []

        for m in self.short_term:

            if query.lower() in str(m).lower():

                results.append(m)

        return results

Add Event Bus

Avoid direct module coupling.


  Section 385: # core/event_bus.py (from NEWMorereliabilty.txt)

class EventBus:

    def __init__(self):

        self.subscribers = {}

    def subscribe(
        self,
        event,
        callback
    ):

        self.subscribers.setdefault(
            event,
            []
        ).append(callback)

    def publish(
        self,
        event,
        data
    ):

        for cb in self.subscribers.get(
            event,
            []
        ):

            cb(data)

Now modules communicate safely.
