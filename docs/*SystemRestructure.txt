def process_input(req):
    intent = detect_intent(req.text)
    
    emotion, confidence = detect_emotion(req)
    
    if confidence < 0.4:
        emotion = None
    
    memory = None
    if intent.get("needs_memory"):
        memory = retrieve_memory(req.user_id, req.text)
    
    return {
        "text": req.text,
        "intent": intent,
        "emotion": emotion,
        "memory": memory
    }

    depth = max(
        MIN_DEPTH,
        0.3 + scores["emotion_strength"] * 0.4
    )
    
    decision = {
        "use_memory": use_memory,
        "depth": depth,
        "tone": "neutral",
        "systems": ["llm"]
    }
    
    decision = apply_budget(decision)
    
    return decision

1️⃣ Core Architecture

Flow:

[User Input]
      ↓
[Perception]
      ↓
[Decision Engine (single brain)]
      ↓
[Execution → generate response]
      ↓
[Multi-Agent Critique Layer]
      ↓
[Learning / Weight Adjustment]

Role of Critique Layer:

Each agent evaluates the response from a different perspective:

Agent A: Empathy / Emotional alignment

Agent B: Relevance / Factual consistency

Agent C: Memory correctness

Agent D: Objective alignment (does the response advance conversation objective?)

Each agent returns a critique score + recommendation:

{
    "pass": True/False,
    "score": 0.0–1.0,
    "recommendation": "increase depth / adjust tone / use memory"
}

Aggregator merges agent critiques to form a final, authoritative adjustment.

2️⃣ Practical Benefits

Error catching: Agents catch hallucinations, irrelevant memory usage, or tone mismatches.

Bias mitigation: No single agent biases learning; critiques come from multiple independent perspectives.

Controlled evolution: Learning only happens if most agents approve or provide actionable feedback.

Stress-proofing: Simulated users + multi-agent critiques = you catch edge cases like sarcasm, contradictions, memory misfires.

📄 1️⃣ Base Agent Interface

critique/agents/base_agent.py

from abc import ABC, abstractmethod

class BaseAgent(ABC):
    """
    Base class for all critique agents.
    Each agent evaluates the proposed response and returns:
    {
        pass: True/False,
        score: 0.0-1.0,
        recommendation: str
    }
    """
    @abstractmethod
    def critique(self, perception, decision, response):
        """
        Evaluate a proposed response and return critique dict with:
        pass (bool), score (0.0-1.0), recommendation (str)
        """
        raise NotImplementedError("Subclasses must implement critique()")

            EmpathyAgent(),

            ConsistencyAgent(),


  # ObjectiveAgent(), EngagementAgent() (from *SystemRestructure.txt)

]

    def run(self, perception, decision, response):
        critiques = []
        overall_pass = True
        weighted_score = 0.0

        for agent in self.agents:
            result = agent.critique(perception, decision, response)
            critiques.append(result)
            if not result["pass"]:
                overall_pass = False
            weighted_score += result["score"]

        weighted_score /= len(self.agents)

        return {
            "pass": overall_pass,
            "weighted_score": weighted_score,
            "critiques": critiques
        }
