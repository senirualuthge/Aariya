================================================================================
                    PHASE 4: PERSONALITY DRIFT MODEL
================================================================================

✅ IMPLEMENTED: Long-Term Adaptive Personality

Files Created:
  - src/systems/PersonalitySystem.jsx

Personality Axes (4 dimensions):
  - Warmth: -1 to +1 (cold ↔ warm)
  - Energy: 0 to 1 (calm ↔ energetic)
  - Assertiveness: 0 to 1 (passive ↔ assertive)
  - Formality: 0 to 1 (casual ↔ formal)

Drift Mechanism:
  - EMA (Exponential Moving Average) with α = 0.01
  - Updates weekly based on aggregated session data
  - Bounded to prevent extremes
  - Reversible (users change over time)

Formula:
  P_new = (1 - 0.01) × P_old + 0.01 × P_target

Impact:
  - Avatar adapts to user over weeks
  - Subtle, not abrupt changes
  - Maintains character identity

6C. PERSONALITY PRESETS

Files Created:
  - src/systems/PersonalityPresets.js

UE5 Principle:

Presets:

Parameters:

Impact:

  - Scales all animations systematically

Files Created:
  - src/systems/BlinkSystem.jsx

UE5 Principle:
  - Blink rate driven by emotion state

Mapping:

6E. MICRO-SACCADES (Critical for Realism)

Files Created:
  - src/systems/EyeMicroMovement.jsx

UE5 Principle:
  - Random ±1° eye drift every 0.8-2 seconds
  - Prevents uncanny "perfect staring"

Implementation:
  - Random offset: ±0.035 radians
  - Timer: 800-2000ms intervals
  - Custom event: 'avatar:microsaccade'

Impact:
  - **Most important for "alive" eyes**
  - Natural eye behavior
  - Breaks uncanny valley

6F. IDLE MOTION SYSTEM

Files Created:
  - src/systems/IdleMotionSystem.jsx

UE5 Principle:
  - Additive motion runs ALWAYS (even in silence)

Components:
  - Breathing: 4-6 second cycle (chest expansion)
  - Weight shift: Subtle sway (15-30 second cycle)
  - Asymmetric shoulders: Left/right desync

Events:
  - 'avatar:breathing'
  - 'avatar:weightshift'
  - 'avatar:shoulders'

Impact:
  - Avatar never looks "frozen"
  - Visible life signs even when idle

---

6G. GAZE BEHAVIOR STATES

Files Created:
  - src/systems/GazeBehaviorSystem.jsx

UE5 Principle:
  - Gaze has states with priority

States:
  - FOCUS_USER: Direct eye contact (user speaking)
  - LISTENING: Intermittent with slight offsets
  - THINKING: Look up-left (classic thinking pose)
  - IDLE_WANDER: Random small cone (3-7 sec changes)

Priority Logic:
  IF UserSpeaking → FOCUS_USER
  ELSE IF IsListening → LISTENING
  ELSE IF IsThinking → THINKING
  ELSE → IDLE_WANDER

Impact:
  - Context-appropriate eye behavior
  - Not staring constantly

7A. AVATAR ANIMATION CONTROLLER

Files Created:
  - src/systems/AvatarAnimationController.jsx

Purpose:
  - Central hub for all animation events
  - Bridges behavior systems → Three.js avatar
  - Stores animation state for Avatar component to consume

Events Handled:
  - avatar:blink → shouldBlink flag
  - avatar:microsaccade → eyeOffset { x, y }
  - avatar:breathing → breathIntensity
  - avatar:weightshift → weightShift value
  - avatar:shoulders → shoulderLeft, shoulderRight
  - avatar:gazestate → gazeState (FOCUS_USER, LISTENING, etc.)
  - avatar:gazetarget → gazeOffset { x, y }
  - avatar:prespeech → preSpeechActive, headLiftAmount, chestExpand

Architecture:
  - Stores animationState ref
  - Publishes to Zustand store for Avatar access
  - Event cleanup on unmount

Impact:
  - Decoupled behavior logic from rendering
  - Avatar component can read animation state via store
  - Clean event-driven architecture

---

7B. PRE-SPEECH ANIMATION SYSTEM

Files Created:
  - src/systems/PreSpeechSystem.jsx

UE5 Principle:
  - Avatar shows "intent to speak" 150-250ms BEFORE TTS starts
  - THIS IS CRITICAL for perceived intelligence

Implementation:
  - Listens to useStore speaking state change
  - Triggers 'avatar:prespeech' event with random 150-250ms delay
  - Sends: headLift (5°), chestExpand (1.05), duration (200ms)

Behavior:
  1. User finishes speaking
  2. AI processes (thinking state)
  3. **150ms BEFORE speech starts** → Head lifts, chest expands
  4. TTS begins
  5. Animation resets after 200ms

Impact:
  - **Makes avatar feel intelligent** (not reactive)
  - Smooth preparation before speaking
  - Human-like anticipation
